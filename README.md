# LUNA MODA

Tienda online de moda femenina — vestidos, blusas, joyería, sombreros y accesorios.
Sitio estático publicado con GitHub Pages.

Estructura:
- `index.html` — página principal
- `css/styles.css` — estilos
- `js/products.js` — catálogo de productos
- `js/app.js` — carrito, búsqueda, filtros y vista rápida
